### HTML: a switch between the text and its preview in the editor (after 0.1.3; priority Next, size M)
Today an HTML file of a folder, of a ZIP or a new text opens only as **source** (colours, edit, save): a page is drawn only inside a snapshot (`wsnp://`), and `availability.ts` prints an HTML file of a folder as text on purpose. The Markdown file has the switch the user wants (`MarkdownToggle`: the formatted page and its text, the choice remembered) and an SVG has one too (`SvgToggle`). **HTML gets the same switch** in the toolbar of its editor: **Preview** and **Source**, for `.html`, `.htm` and `.xhtml`, the same position and the same behaviour as Markdown's (the choice is a setting and a toolbar button, per tab it is remembered).
- [ ] **The switch**: **Preview** draws the page; **Source** is the editor as it is (undo history, selection, scroll and unsaved changes kept: the buffer stays in `editorBuffers` and is never reloaded by the switch); a key for it (`Alt+P`?, to decide) and an item in the right-click menu and the palette; a **Save**, **Save As** and the **Modified** mark are in the toolbar of the preview too
- [ ] **The preview shows the buffer, not the file on the disk**: what is typed and not yet saved is what is drawn (refreshed a moment after the typing stops, about 300 ms, with the **scroll position kept** through the reload); a page of a file that has **not** been edited is drawn from the file as it is
- [ ] **Relative files are found** (`style.css`, `img/logo.png`, `script.js`, fonts, `../shared/site.css`): the page's addresses are resolved by a **protocol of its own** (`fb-html://<token>/…`, the token naming the open root and the folder of the page) that serves only **files of that root**, by the same checks as every read (`resolveInside`, `realpath`, a `..` or a link that leaves the root is refused, nothing outside an open root ever); for a file **in a ZIP** the siblings are the entries of the ZIP, for a **snapshot** nothing changes (it is `wsnp://`); the type of each file is told by its name, with `nosniff`
- [ ] **Nothing leaves the computer and the page cannot reach the application**: a frame with `sandbox` and **no** `allow-same-origin`, `allow-top-navigation`, `allow-popups`, `allow-downloads` or `allow-forms` (an opaque origin: it cannot see `window.fb`, the application's storage or other pages); a **CSP** on every response (`default-src 'none'`; images, styles, fonts and media only from `fb-html:` and `data:`; `connect-src 'none'`; no frames of its own); **every request that is not for a file of its own root is cancelled** (as `snapshot-view.ts` does with `webRequest.onBeforeRequest`: web addresses, `file:`, `ftp:`), and a notice counts what was blocked ("3 web resources were blocked: nothing leaves the computer"), with the list on a click
- [ ] **Scripts**: off by default when a page is drawn (the CSP lets through only the application's own script, the one of `core/frameScript.ts` that carries the zoom keys and the wheel, never the page's), and a toolbar button **Run Scripts** that turns the page's own scripts on for that tab (still sandboxed, with no network and no access to the application: a script can draw, and cannot read a file outside its root), remembered as a setting (see "Settings"); the button says what it does and the page is drawn again when it changes
- [ ] **Links**: a link to a **place in the page** (`#id`) scrolls; a link to **another file of the root** (`other.html`) **opens in a new tab** (a preview tab, as a click in the tree does) unless the setting says to go there in the same frame; a link to the **web** is never followed by the frame: it asks (the application's own confirmation) and opens in the browser; `mailto:` and others are said and not followed
- [ ] **As the other pages**: **zoom per tab** (the frame laid out at 1/zoom and scaled, as the snapshot's and the documents'), **Find** acts on the page (the frame registers as `fileTarget`), **Print** and **Save as PDF** through a hidden window on the same address, **Select All** and **Copy**, and the right-click menu of the page (Copy, Select All, Print) drawn by the application
- [ ] **Where it applies**: a file of a folder or of a ZIP (the page and its siblings), a **new text** (an HTML written in the window, with no siblings: only what is in the page and `data:`), an HTML **entry of a snapshot** keeps its page (nothing changes), and the **read-only** views (diff, a log) are not touched
- [ ] **A split view** (later, size S to M): **Preview Beside the Source** shows the editor on one side and the live preview on the other inside the tab (the same file cannot be in two groups, and the user asked for the alternation first); a divider to resize and the same refresh rule
- [ ] **Performance**: the first page of a file is drawn in about a quarter of a second after the switch (the frame and the protocol are created once and reused, the root's reads are by the existing registry), typing keeps its 60 frames (the refresh is debounced and never on the typing's thread; a page over a limit, say 5 MB, is **not** live-refreshed and says so), the frame is **destroyed when the tab closes** and its token released, the **hidden frames of several previews** are kept at most a few and the oldest dropped, and nothing is polled
- [ ] **Tests**: the protocol's resolution of relative, `..`, absolute, `%2e%2e`, encoded slashes, a link out of the root, a file in a ZIP and a missing file (404 in plain words); the CSP and the frame's `sandbox` attributes as data; the cancellation of web, `file:` and `ftp:` requests with the count; the scroll kept through a refresh; a page with external CSS and an image **blocked and counted**; the toggle keeping the buffer and the undo history; Run Scripts on and off (a script that tries `fetch`, `window.parent.fb` and a cookie: all fail); zoom, Find and Print on the frame; and an end-to-end spec in which a folder holds `index.html`, `style.css` and `logo.png`: toggle to Preview, see the style applied, edit the source, see the preview follow without saving, and see an `http://` image blocked
- **Decisions to make**: **the default** when an HTML file opens (**Source**, as today, the recommendation, with the choice remembered per type; or Preview); **scripts** off by default (the recommendation) or on; **links to other files** in a new tab (the recommendation) or in the same frame; whether the **split view** comes with the first version or later; and whether the same switch also applies to **`.xml` with an XSLT**, **`.svg`** (it has its own) and **`.md` with embedded HTML** (it follows the Markdown rules: no script ever)

## Data files: a SQLite viewer and JSON, YAML and XML tools (after 0.1.3; priority Next for SQLite, Later for the others)
- [ ] **Open a SQLite database** (`.sqlite`, `.sqlite3`, `.db`, `.db3`; told by the first 16 bytes, not the name alone): a tab with the **list of tables, views and indexes** (with their rows' count), the **columns and types** of the one chosen, its **rows in a virtual table** (the table view that CSV has: sort, filter, search), the **schema** as text, and a **query box** that runs one read-only `SELECT`, `WITH` or `PRAGMA table_info` (the same checks and `PRAGMA query_only = ON` as the CSV's query), with **Export to CSV** of what the table or the query shows; it opens the file **read-only** (a copy in memory up to a limit, or by ranges for a big one, never the file written; a database with a `-wal` file is read as `immutable` or the user is told), and it never runs what a database holds (no extensions, no triggers or views that write: only the reads the user asks for)
- [ ] **Editing a SQLite database** is **not** planned in the first version; a later one could edit a cell or a row, through the safe save and Local History
- [ ] **JSON, YAML and XML**: a **tree view** beside the text (fold, search, copy the path of a node), **validation with the line and column of the error** in plain words, **Format**, **Minify** and **Sort keys** (as edits that can be undone), and a **query** box (JSONPath for JSON, XPath for XML) whose matches are listed and selected; for a big file (over 5 MB) a read-only streamed tree, never a freeze
- [ ] Performance and tests: a database of 1 GB opens at once (the file is read by ranges: only the pages a query touches), a table of a million rows scrolls as a window, a query runs in the worker with the 10 s limit; tests with a SQLite file built by sql.js in the fixtures (tables, a view, a blob, an index, a corrupt header, a locked WAL), the same safety tests as the CSV query, and an end-to-end spec (open, browse, query, export)
